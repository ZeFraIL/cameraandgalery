# Activity: MainActivity

## 1. Общая информация
*   **Имя класса:** `MainActivity`
*   **Тип:** Activity (Главный экран)
*   **Назначение:** Это «Центр управления». Обрабатывает основные действия пользователя: съемку фото, видео, просмотр галереи и переход к списку файлов.
*   **Взаимодействие с другими компонентами:** Запускает камеру, использует `DatabaseHelper` для фоновой записи, открывает экран просмотра списка.

## 2. Переменные (поля класса)
| Имя | Тип | Назначение |
| :--- | :--- | :--- |
| `currentPhotoPath` | `String` | Хранит временный путь к сделанному фото. |
| `currentVideoPath` | `String` | Хранит временный путь к записанному видео. |
| `takePictureLauncher` | `ActivityResultLauncher` | Способ получения результата съемки фото. |
| `takeVideoLauncher` | `ActivityResultLauncher` | Способ получения результата записи видео. |
| `requestCameraPermissionLauncher` | `ActivityResultLauncher` | Запрос разрешения на использование камеры. |
| `dbHelper` | `DatabaseHelper` | Объект для связи с базой данных. |
| `executorService` | `ExecutorService` | Фоновый поток для асинхронной записи в БД. |

## 3. Методы класса
### Имя метода: `checkCameraPermissionAndExecute`
*   **Что делает метод:** Проверяет наличие разрешения `Manifest.permission.CAMERA`. Если есть — запускает съемку, иначе — запрашивает разрешение.

### Имя метода: `dispatchTakePictureIntent`
*   **Что делает метод:** Создает пустой файл, подготавливает запрос к камере через `FileProvider` и запускает её.

### Имя метода: `saveFileInfoToDatabase`
*   **Что делает метод:** Выполняет фоновую запись имени файла, даты, времени и URI в локальную БД через `executorService`.

## 4. Жизненный цикл
*   **`onCreate()`**: Настраивает Edge-to-Edge интерфейс, регистрирует лаунчеры разрешений/камеры и устанавливает слушатели кнопок.
*   **`onDestroy()`**: Завершает работу `executorService`.

## 5. Взаимодействие с интерфейсом (UI)
*   **Кнопки:** Съемка фото, Съемка видео, Галерея, Инфо.
*   **Edge-to-Edge:** Автоматическая обработка системных отступов (`WindowInsets`).

## 6. Взаимодействие с другими компонентами
*   **Системная камера:** Через `Intent` и `FileProvider`.
*   **База данных:** Через `DatabaseHelper` в фоновом потоке.
