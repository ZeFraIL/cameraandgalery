# Класс: DatabaseHelper

## 1. Общая информация
*   **Имя класса:** `DatabaseHelper`
*   **Тип:** Обычный класс (наследует `SQLiteOpenHelper`)
*   **Назначение:** Управляет локальной базой данных (SQLite). Отвечает за создание таблицы, обновление структуры и безопасность соединений.

## 2. Переменные (поля класса)
| Имя | Тип | Назначение |
| :--- | :--- | :--- |
| `DATABASE_NAME` | `String` | Имя файла базы данных (`all_info.db`). |
| `TABLE_NAME` | `String` | Название таблицы. |
| `COLUMN_...` | `String` | Названия колонок таблицы. |

## 3. Методы класса
### Имя метода: `insertFileInfo`
*   **Что делает метод:** Упаковывает данные в `ContentValues` и вставляет запись в таблицу, сохраняя подключение открытым для последующих вызовов.

## 4. Жизненный цикл
Управляется системой Android и классом `SQLiteOpenHelper`.
