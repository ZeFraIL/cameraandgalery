# Activity: Start

## 1. Общая информация
*   **Имя класса:** `Start`
*   **Тип:** Activity (Заставочный экран)
*   **Назначение:** Это «Splash Screen» (заставочный экран). Он показывает временный экран с логотипом перед тем, как перевести пользователя в основное приложение.
*   **Взаимодействие с другими компонентами:** Запускает `MainActivity` через 2 секунды и завершает работу.

## 2. Переменные (поля класса)
| Имя | Тип | Назначение |
| :--- | :--- | :--- |
| `cdt` | `CountDownTimer` | Таймер обратного отсчета для показа заставки. |

## 3. Методы класса
### Имя метода: `onCreate`
*   **Что делает метод:**
    1. Устанавливает макет экрана и Edge-to-Edge отступы.
    2. Запускает таймер `CountDownTimer` на 2 секунды.

### Имя метода: `onDestroy`
*   **Что делает метод:** Отменяет таймер `cdt` для предотвращения утечки ресурсов.

## 4. Жизненный цикл
*   **`onCreate()`**: Настраивает интерфейс и запускает таймер.
*   **`onDestroy()`**: Безопасно отменяет активный таймер.

## 5. Взаимодействие с другими компонентами
*   **MainActivity:** Переходит на этот экран и завершает себя вызовом `finish()`.
