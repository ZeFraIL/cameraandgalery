# Activity: ViewInfoAboutMyFiles

## 1. Общая информация
*   **Имя класса:** `ViewInfoAboutMyFiles`
*   **Тип:** Activity (Экран списка)
*   **Назначение:** Загружает все записи из базы данных в фоновом потоке и показывает их в виде прокручиваемого списка.
*   **Взаимодействие с другими компонентами:** Читает данные через `DatabaseHelper`, использует `FileInfo` и `Glide` для отрисовки превью фото и видео.

## 2. Переменные (поля класса)
| Имя | Тип | Назначение |
| :--- | :--- | :--- |
| `recyclerView` | `RecyclerView` | Список элементов на экране. |
| `fileInfoList` | `List<FileInfo>` | Коллекция объектов с данными о файлах. |
| `executorService` | `ExecutorService` | Фоновый поток для чтения из БД. |
| `mainHandler` | `Handler` | Передача результатов из фонового потока в UI. |

## 3. Методы класса
### Имя метода: `loadFileInfoFromDatabase`
*   **Что делает метод:** В фоновом потоке запрашивает данные из SQLite, формирует список `FileInfo` и обновляет UI через `mainHandler`.

### Имя метода: `showFileInfoDialog`
*   **Что делает метод:** Создает всплывающее окно (диалог) с детальной информацией, фото или интерактивным видеоплеером (с `MediaController`).

## 4. Жизненный цикл
*   **`onCreate()`**: Включает Edge-to-Edge, инициализирует RecyclerView и запускает асинхронную загрузку.
*   **`onDestroy()`**: Завершает работу `executorService`.

## 5. Взаимодействие с интерфейсом (UI)
*   **RecyclerView & Glide:** Асинхронная загрузка кадров-превью видео и фото.
*   **VideoView & MediaController:** Управление воспроизведением видео в диалоге.
