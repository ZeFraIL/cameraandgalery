## 🎯 هدف المشروع
•	**المهمة التي يحلها التطبيق:** يسمح للمستخدم بالتقاط الصور وتسجيل الفيديو، مع حفظ البيانات الوصفية للملفات تلقائياً (الاسم، التاريخ، الوقت، المسار) في قاعدة بيانات محلية للمراجعة اللاحقة.
•	**لماذا هذه المهمة مهمة:** يسهل تنظيم ملفات الوسائط ويوفر وصولاً سريعاً إلى المعلومات حول الملفات التي تم إنشاؤها في مكان واحد.
•	**الجمهور المستهدف:** المستخدمون الذين يحتاجون إلى تتبع محتوى الوسائط الذي قاموا بإنشائه.
________________________________________
## 📌 متطلبات التطبيق
### المتطلبات الوظيفية
•	التقاط الصور باستخدام كاميرا النظام.
•	تسجيل الفيديو باستخدام كاميرا النظام.
•	حفظ معلومات الملف (الاسم، التاريخ، الوقت، URI) في SQLite.
•	عرض قائمة بجميع السجلات المحفوظة.
•	عرض تفاصيل الملف (معاينة الصورة أو تشغيل الفيديو مع أدوات التحكم) في مربع حوار منبثق.
•	فتح معرض الصور الخاص بالنظام.

### المتطلبات غير الوظيفية
•	**الأداء:** تحميل سريع لقائمة الملفات من قاعدة البيانات في الخلفية باستخدام RecyclerView و ExecutorService.
•	**سهولة الاستخدام:** واجهة بسيطة مع أربعة أزرار رئيسية في الشاشة الرئيسية مع دعم حواف الشاشة (Edge-to-Edge).
•	**الموثوقية:** التعامل الحديث مع الأذونات (`ActivityResultContracts.RequestPermission`) والمشاركة الآمنة للملفات عبر FileProvider.

## 🧩 وصف تفصيلي للفئات
### 📌 الفئة: Start
**الدور:** شاشة البداية (Splash Screen).
**المسؤولية:** تعرض شاشة البداية لمدة ثانيتين، وتلغي المؤقت بأمان في `onDestroy()`، وتشغل `MainActivity` وتنهي نفسها عبر `finish()`.

### 📌 الفئة: MainActivity
**الدور:** شاشة التطبيق الرئيسية.
**المسؤولية:** إدارة دورة الحياة، التعامل مع نقرات الأزرار، تشغيل Intents للكاميرا/الفيديو، طلب إذن الكاميرا حديثاً، والحفظ غير المتزامن في قاعدة البيانات.

### 📌 الفئة: DatabaseHelper
**الدور:** طبقة البيانات SQLite.

### 📌 الفئة: ViewInfoAboutMyFiles
**الدور:** شاشة عرض القائمة.
**المسؤولية:** تحميل البيانات في الخلفية من SQLite، وعرض العناصر في RecyclerView مع معاينات للصور والفيديو عبر Glide، وعرض حوار التفاصيل مع عناصر التحكم في الفيديو (`MediaController`).

## ⚙️ التعامل مع الخيوط (Threading)
•	**الاستخدام:**
- تتم قراءة وكتابة قاعدة بيانات SQLite بشكل غير متزامن في خيط الخلفية باستخدام `ExecutorService`.
•	**منع التوقف (ANR):**
- نقل عمليات الإدخال/الإخراج لقاعدة البيانات من الخيط الرئيسي.
- استخدام Glide للتحميل غير المتزامن والتخزين المؤقت لمعاينات الصور والفيديو.
